# CloudNS PHP 版（服务器部署）

Node 版的完整 PHP 移植，适配 **PHP 8.0+（推荐 8.2）+ MySQL 5.6/5.7**，可直接跑在宝塔等 LNMP/LAMP 环境，功能与界面与原版一致：

- 仿 Cloudflare 仪表盘控制台（`dashboard.php`）：移动端抽屉侧栏、域名列表、DNS 记录卡片页
- 新增仿 Cloudflare 官网风格的**首页介绍页**（`index.php`）
- 全站图标使用 SVG，无 emoji
- 二级域名分发：积分购买、续期、DNS 记录增删改（直连 Cloudflare / DNSPod / 阿里云）
- 购买时可填一个 IP 或目标域名，自动创建 `@` 解析记录（A / AAAA / CNAME）
- 邮件通知（自建 SMTP 客户端，不依赖任何扩展组件）：注册验证码、找回密码、到期提醒
- 到期处理：到期前 7/3/1 天提醒 → 暂停解析 → 宽限期后自动回收
- 充值（彩虹易支付 + 沙盒收银台）、每日签到、积分日志、完整管理后台

## 目录结构

```
php/
├─ index.php            首页（介绍页）
├─ dashboard.php        控制台（SPA 外壳）
├─ api.php              全部后端接口（前端通过 ?api=xxx 调用）
├─ install.php          网页安装向导（建库建表 + 初始管理员）
├─ cron.php             到期处理定时任务入口（命令行或带密钥 URL 触发）
├─ .htaccess            Apache 伪静态与目录保护
├─ app/                 应用代码（禁止 HTTP 直接访问）
│  ├─ bootstrap.php     配置加载 / PDO / 会话 / 默认设置项
│  ├─ config.sample.php 配置模板（安装向导会自动生成 config.php）
│  ├─ helpers.php       前缀/记录/域名校验
│  ├─ auth.php          登录态、积分事务
│  ├─ ratelimit.php     MySQL 限流表
│  ├─ mailer.php        SMTP 客户端 + 邮件模板 + 发送日志
│  ├─ mailcode.php      邮箱验证码（只存哈希，10 分钟有效）
│  ├─ expire.php        到期提醒 / 暂停 / 回收（cron 与后台共用）
│  ├─ epay.php          易支付 MD5 签名/验签
│  ├─ providers.php     Cloudflare / DNSPod / 阿里云 / mock
│  └─ routes/           auth / domains / pay / admin 接口
├─ assets/              前端 css / js
├─ data/                mock 服务商记录文件（需可写）
└─ deploy/              nginx 配置示例
```

## 部署步骤（宝塔面板）

1. 新建站点，PHP 版本选择 **8.2**，创建 MySQL 数据库（记下库名/用户名/密码）。
2. 把 `php/` 目录**内部的所有文件**上传到站点根目录。
3. （Nginx）站点设置 → 配置文件，参考 `deploy/nginx.conf.example` 增加：
   - `location ~ ^/(app|data)/ { deny all; }`
   - `fastcgi_split_path_info` 与 `fastcgi_param PATH_INFO`（易支付回调需要）。
     回调地址固定用 `…/api.php/pay/notify` 这种 PATH_INFO 形式：验签会把查询串里的全部参数一起计算，若改用 `api.php?api=pay/notify`，多出的 `api` 参数会进签名串导致验签失败。
   （Apache）`.htaccess` 已包含目录保护与伪静态，无需额外配置。
4. 浏览器访问 `https://你的域名/install.php`，填写数据库信息与管理员账号，点击安装。
5. 安装成功后**删除 install.php**，访问：
   - 首页介绍页 `https://你的域名/`
   - 控制台 `https://你的域名/dashboard.php`
6. 进控制台 → 管理后台：
   - 「DNS 服务商」添加 Cloudflare Token / DNSPod / 阿里云密钥（内置演示可不改）；
   - 「主域名」添加已托管在对应服务商的根域名并设定积分价格与限购数量；
   - 「邮件与到期」填写 SMTP、开关提醒与自动回收，并生成计划任务密钥；
   - 「系统设置」按需填易支付网关、PID、KEY（不填则走沙盒收银台）。
7. 配置计划任务（见下文「邮件与到期处理」），否则到期提醒与自动回收不会执行。
8. 在 DNS 服务商处给主域名添加泛解析（如 `*.example.com` 指向你的站点/源站），用户注册的二级域名才能真正解析。

## 邮件与到期处理

### SMTP

管理后台「邮件与到期」卡片填写即可，无需改代码：

| 项 | 说明 |
| --- | --- |
| 服务器 / 端口 / 加密 | 465 选 `SSL`（直连），587 选 `STARTTLS`，25 选 `不加密` |
| 账号 / 密码 | QQ、163 等邮箱要填**授权码**而不是登录密码 |
| 发件邮箱 | 留空则用登录账号；建议与账号一致，否则容易被判垃圾邮件 |
| 校验服务器证书 | 默认开启。若 PHP 未配置 CA 根证书（报 `unable to get local issuer certificate`），或使用的是内网/自签名证书，关闭它 |
| 站点地址 | 邮件里链接的前缀，留空则用当前请求域名 |

「发送测试邮件」会真实投递一封并写进 `cns_mail_logs`，失败原因直接显示在页面上。
`mail_enabled` 关闭时所有邮件只写日志、不发送，注册验证码与到期提醒随之停用（注册回退为不校验验证码）。

开启「注册需要邮箱验证码」后，注册页会出现验证码输入框；忘记密码走同一套验证码，场景互相隔离，
验证码只存 `sha256(邮箱|场景|码)`，10 分钟有效、最多试 5 次、校验通过立即作废。

### 到期规则

- 管理员在「主域名」里设定每个根域名的积分单价，购买/续期按原价扣积分。
- 到期前 **7 / 3 / 1 天**各发送一封提醒邮件，同一档位只发一封；同一轮扫描最多发一封。
- 到期当天：调用服务商 API 摘除上游解析记录，本地记录保留（`external_id` 置空），状态转为「已到期」，
  此时域名仍可浏览记录但**任何写入都会被拒绝（409）**。
- 宽限期内（默认 7 天，可调 0-60）按原价续期，会自动把全部记录重新发布回上游并恢复状态。
- 宽限期从**真实到期时间**起算，不是从被扫描到的那一刻起算：计划任务停机期间到期的域名，
  下一轮会先补做暂停，再下一轮直接回收，不会白送一段宽限期。
- 超出宽限期仍未续期：删除该域名与全部解析记录、释放前缀，并发送回收通知邮件；
  「宽限期后自动删除」关闭时只标记待回收、不删除。

### 计划任务

必须有一个周期任务来驱动上面这套状态机。宝塔 → 计划任务 → 添加「Shell 脚本」，每 30 分钟或每天一次：

```
/www/server/php/82/bin/php /www/wwwroot/你的站点/cron.php >/dev/null 2>&1
```

无法登录服务器执行 PHP 时，改用带密钥的 URL（在「邮件与到期」卡片生成，可随时重新生成）：

```
curl -s "https://你的域名/cron.php?token=密钥" >/dev/null 2>&1
```

- 未生成密钥时 `cron.php?token=` 一律返回 403；命令行方式不受限制，但只能在本机执行。
- 同页「立即执行一次到期检查」可手动跑一轮，并把每一行的处理结果回显出来，便于排错。

## 环境要求

- PHP >= 8.0，扩展：`pdo_mysql`、`curl`、`mbstring`、`openssl`（宝塔默认均开启）
- MySQL >= 5.6（推荐 5.7，utf8mb4）
- `data/` 目录需可写（仅使用内置演示服务商时需要）
- 出站放行 SMTP 端口：部分机房默认封 25，建议用 465 或 587

## 与 Node 版的差异

| | Node 版 | PHP 版 |
| --- | --- | --- |
| 数据库 | SQLite | MySQL 5.7 |
| 会话 | 数据库 token + Cookie | PHP 原生会话（Cookie: CNSSESSID） |
| 限流 | 内存桶 | `cns_rate_limits` 表（多进程一致） |
| 密码 | scrypt | bcrypt（`password_hash`） |
| 接口 | `/api/*`（Express） | `/api.php?api=*`（免伪静态，兼容宝塔默认 Nginx） |
| 邮件 | 无 | 自建 SMTP 客户端（`smtp_send`），只用 openssl + socket |

业务规则（保留前缀、记录校验、积分/充值/签到逻辑、易支付签名协议）与 Node 版完全一致。

## 安全提醒

- 安装完成后删除 `install.php`；
- `app/config.php` 含数据库密码，不要提交进仓库、不要通过 HTTP 访问，确认站点已按上文 deny 规则保护；
- `cron.php?token=` 属于免登录入口，密钥泄露等于任何人都能触发回收，定期在后台重新生成；
- 关闭「校验 SMTP 服务器证书」会让发件账号密码暴露在可能的中间人攻击下，仅在可信网络里使用；
- 上线后立即在管理后台修改管理员密码。
